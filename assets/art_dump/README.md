# Art dump

Stuff we drew for the jam that never made it into the game. Everything the game actually uses lives in `public/assets`.

- `characters/`: two more characters (the cat wizard and the red fox guy) that never got character cards.
- `cards/`: blank card frames for each card type, plus the character card back.
- The loose icons (ice, eldritch horror, chest, mana crystal, healing potion) were meant to become cards and didn't.
- `buttons.png` and `buttons_2.png`: UI bits we never used.
- `portal.png`: an earlier version of the title screen background.
